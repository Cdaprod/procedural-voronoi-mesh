# Changelog

## 1.0.0

- Installable Python library, CLI and loopback browser UI using one generator.
- Deterministic sites, relief styles, masks, sampled relaxation and explicit solidification.
- Fifteen populated presets including the four preserved Doesbot-era names.
- Procedural plane/box and STL/OBJ/GLB input; STL/OBJ/GLB/3MF output.
- Reloaded mesh validation and optional independent CGAL checks.
- Saved inputs, resolved YAML, dependency versions, manifests and reproduction.
- Actual generated examples, visual documentation, provenance and engineering story.
- Tests, CI, package and documentation-image checks.

Existing repository history is preserved. Doesbot enclosure CAD remains external.
